# Лиды — копия интерфейса со скриншота

Проект содержит pixel-like верстку страницы «Лиды», CSV-выгрузку на PHP и SQL-файл с таблицей и демо-данными для MySQL.

## Размер логотипа

Подготовьте логотип **40×40 px**. На мобильных экранах контейнер уменьшается до **34×34 px**, поэтому лучше использовать квадратный PNG/SVG с прозрачным фоном или без важных деталей по краям.

Чтобы заменить временный знак, вставьте изображение в блок `.logo-slot` в `index.php`, например:

```html
<img src="assets/logo.png" alt="Логотип" width="40" height="40">
```

## Запуск локально

```bash
php -S 127.0.0.1:8000
```

После запуска откройте `http://127.0.0.1:8000`.

## Как вставить таблицу в БД

1. Создайте базу и таблицу вместе с демо-данными из файла:

```bash
mysql -u root -p < database.sql
```

2. Укажите доступы к MySQL через переменные окружения:

```bash
export DB_HOST=127.0.0.1
export DB_NAME=leads_demo
export DB_USER=root
export DB_PASSWORD=your_password
php -S 127.0.0.1:8000
```

Можно также поменять значения по умолчанию в `config.php`.

Если `DB_HOST` не задан или MySQL недоступен, страница автоматически показывает встроенные демо-данные, чтобы внешний вид оставался как на скриншоте.

## Файлы проекта

- `index.php` — основная страница с таблицей лидов.
- `assets/styles.css` — вся визуальная стилизация, адаптивность, цвета, отступы и таблица.
- `assets/app.js` — переключение активной вкладки.
- `api.php` — обработчик скачивания CSV.
- `config.php` — настройки подключения к MySQL.
- `database.sql` — SQL-схема и демо-данные.
